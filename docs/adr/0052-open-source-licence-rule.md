# AD-52 Open-source licence rule

- Status: Proposed
- Source: DP-AI-001-C v0.2, chapter 10

## Decision

Only OSI-approved open-source components besides LangSmith. Permissive licences preferred; copyleft (MPL, LGPL, AGPL) accepted for unmodified use; source-available licences such as the Business Source Licence refused.

## Reason

No vendor lock-in or subscription cost; any customer can run and inspect the stack.
