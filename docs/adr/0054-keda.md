# AD-54 KEDA and metrics-server are platform components

- Status: Proposed
- Source: DP-AI-001 Solution Architecture v2.0, chapter 14

## Decision

KEDA is installed by Argo CD; RKE2's bundled metrics-server is kept.

## Reason

LangChain requires KEDA for self-hosted LangSmith Deployment and prefers it for queue scaling; SmithDB's autoscalers need metrics-server.
